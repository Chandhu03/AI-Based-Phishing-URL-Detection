The workspace is not synchronised. Another browser, device or person cannot see it. Clearing site data, or deleting the workspace, removes it permanently.

What it never does

  • Visit, fetch, resolve or screenshot a link you submit.
  • Send a link, alert, note or indicator to any server, including ours.
  • Use cookies, analytics, advertising or third-party scripts and fonts.
  • Call a reputation or threat-intelligence service. If an enrichment integration is ever added, it will be opt-in, documented, and isolated from the core analysis.

Browser-enforced controls

Every response carries this Content Security Policy. connect-src 'none' means the page cannot make network requests at all, so the promises above do not depend on our code behaving.

default-src 'none'; script-src 'self'; style-src 'self'; img-src 'self' data:; font-src 'self'; connect-src 'none'; manifest-src 'self'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'; require-trusted-types-for 'script'; trusted-types 'none'; upgrade-insecure-requests

  • No inline code. Scripts and styles come only from this site’s own hashed files.
  • No framing. frame-ancestors 'none' and X-Frame-Options: DENY block clickjacking.
  • Transport. HTTPS only, with HSTS; TLS 1.0 and 1.1 are refused.
  • Isolation. Cross-Origin-Opener-Policy and Cross-Origin-Resource-Policy are set to same-origin; a Permissions-Policy disables camera, microphone, location, payment and USB.

Threat model

ThreatControl
A crafted link injects scriptAll output is written as text, never parsed as HTML; CSP forbids inline and third-party scripts.
Analysis triggers a request to an attacker (SSRF, tracking pixels, DNS)No code path fetches the link; connect-src 'none' blocks requests even if one were added.
Disguised destinations (look-alike letters, encoded IPs, user@host)The browser’s own parser is used, then differences between what was written and what the browser reads are reported.
A malicious import fileSize limit, schema validation, per-record re-validation; values are rendered as text.
Spreadsheet formula injection in exportsCSV cells that start with = + - @ are neutralised.
Embedded passwords in links leak into reportsLogin text before @ is never stored in output fields or exports.
Accidental clicks from reportsExports and indicator lists defang URLs (hxxps://example[.]com).
Tampered model or rule filesModel and Public Suffix List ship as code-free data modules built from pinned, hash-verified sources.

Limits

  • Anyone with access to this browser profile can read the workspace. Use an operating-system account you control, and treat exported backups as sensitive.
  • Browsers may evict site storage under pressure unless persistence is granted (Settings shows the status).
  • Verdicts are evidence for a person to weigh, not an automated block decision.

Report a vulnerability

Email founder@securemindlabs.com; details are also in security.txt. Please do not include live credentials or private links. The code is open: github.com/Chandhu03/AI-Based-Phishing-URL-Detection (opens in a new tab).
